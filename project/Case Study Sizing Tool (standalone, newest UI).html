Predicted performance curve — trim-diameter family slide 21
Family generated via standard affinity-law scaling (Q∝D, H∝D²) of the sized (100%) curve — the same method vendor curve sheets use to show a trim range off one tested casing. Blade angle + BEP-locked slip velocity held fixed across flow, computed down to half the BEP flow; the dashed segment below that is a blend into the shutoff head (Karassik Eq. 65/66), per Karassik p.2.68. Each trim is a scaled copy of the same underlying shape (affinity laws don't independently re-derive a curve per diameter), so all trims look near-linear together at low-to-mid Ωₛ — expected physics per Karassik (rise-to-shutoff curvature grows with specific speed; see the gap note below), not a rendering bug.

Self-contained: no external scripts, no CDN, no network calls. Fluid properties are a precomputed thermo lookup table baked in at build time. Formulas trace to slide numbers in Centrifugal Pump Sizing.pptx; where the deck only gives a chart/qualitative guidance, a documented approximation is used and flagged below. CFD verification (slides 22–23) is out of scope for a closed-form calculator. Q/H slider bounds and the two corner flags are an approximate reading of Pump Selection Guidelines.png (Fig. 10-24-style pump coverage chart), not a pixel digitization.
